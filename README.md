# Block Buster

A brick breaker game in C++ with SFML 3 (PF Mini Project).

## Controls

| Key | What it does |
|-----|--------------|
| Left / A | Move paddle left |
| Right / D | Move paddle right |
| Space | Launch the ball |
| Up / Down | Choose a menu option |
| Enter | Select (menu), back to menu (game over / you win) |
| Esc | Save the game and go back to the menu |

## How to run

1. Install Visual Studio 2022 with "Desktop development with C++".
2. Download SFML 3 (Visual C++ 17 (2022), 64-bit) and extract it to `C:\SFML`.
3. Open `BlockBuster.slnx` (or `.sln`) in Visual Studio.
4. Choose **Debug** and **x64** at the top, then press **F5**.
5. `level.txt` must be in the same folder as `main.cpp`.
